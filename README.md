# FastAPI blog posting website:

This project is a practice of how to use fastapi, from basic crud operation to security authorizations from this tutorial by [Corey Schafer](https://www.youtube.com/watch?v=7AMjmCTumuo&list=PL-osiE80TeTsak-c-QsVeg0YYG_0TeyXI), he thoroughly discusses the importance of fastapi. But in my project I use tailwind instead of bootstrap just so I could have a bit of difference but also following his style. I've done the tutorial up till the pagination because I think I've gained enough kowledge to understand fastapi.
